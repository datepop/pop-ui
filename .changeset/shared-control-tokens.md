Expose shared action background, field border and placeholder color tokens. Use the same control heights for Button, TextField and Dropdown in the web components and Penpot library. The placeholder now uses gray 700. Medium Button labels share a typography token for 16px semibold text with a 20px line height. TextField and Dropdown share hover and focus border colors and keep error borders visible during interaction. TextField, Dropdown and SearchBar use independent error border and message tokens.
